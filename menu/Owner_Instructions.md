# Lazy House Menu — How to Update
# คู่มือการอัปเดตเมนู Lazy House

---

## 🇬🇧 English Instructions

The menu on the website reads directly from a **Google Sheet** that you control. No coding needed!

### How to edit the menu

1. Open the Google Sheet that was shared with you (bookmark it!).
2. The sheet has **6 columns**:

| Column | What to write | Example |
|--------|---------------|---------|
| **category** | Category name (English) | Ramen |
| **name_en** | Dish name in English | Tonkotsu Ramen |
| **name_th** | Dish name in Thai | ทงคตสึราเมน |
| **description_en** | Short description in English | Rich pork broth ramen |
| **description_th** | Short description in Thai | ราเมนซุปกระดูกหมู |
| **price** | Price number only (no ฿ symbol) | 250 |

3. **To add a new dish:** Add a new row at the bottom. Type the category name exactly as it appears in other rows.
4. **To remove a dish:** Delete the entire row.
5. **To add a new category:** Just type a new category name in column A. It will appear automatically.
6. **Save.** The website updates automatically within a few minutes! ✨

### Important Rules
- ❌ Do NOT rename or reorder the columns in row 1 (the header row).
- ❌ Do NOT add extra sheets — only "Sheet 1" is read.
- ✅ You CAN reorder rows — dishes appear in the order they are listed.

## 🇹🇭 คำแนะนำภาษาไทย

เมนูบนเว็บไซต์จะอ่านข้อมูลจาก **Google Sheet** ที่คุณควบคุมโดยตรง ไม่ต้องเขียนโค้ด!

### วิธีแก้ไขเมนู

1. เปิด Google Sheet ที่แชร์ให้คุณ (บุ๊กมาร์กไว้เลย!)
2. ชีทมี **6 คอลัมน์**:

| คอลัมน์ | เขียนอะไร | ตัวอย่าง |
|---------|-----------|----------|
| **category** | ชื่อหมวดหมู่ (ภาษาอังกฤษ) | Ramen |
| **name_en** | ชื่ออาหารเป็นภาษาอังกฤษ | Tonkotsu Ramen |
| **name_th** | ชื่ออาหารเป็นภาษาไทย | ทงคตสึราเมน |
| **description_en** | คำอธิบายสั้นๆ ภาษาอังกฤษ | Rich pork broth ramen |
| **description_th** | คำอธิบายสั้นๆ ภาษาไทย | ราเมนซุปกระดูกหมู |
| **price** | ตัวเลขราคาเท่านั้น (ไม่ต้องใส่ ฿) | 250 |

3. **เพิ่มเมนูใหม่:** เพิ่มแถวใหม่ที่ด้านล่าง พิมพ์ชื่อหมวดหมู่ให้ตรงกับแถวอื่นๆ
4. **ลบเมนู:** ลบทั้งแถว
5. **เพิ่มหมวดหมู่ใหม่:** พิมพ์ชื่อหมวดหมู่ใหม่ในคอลัมน์ A จะปรากฏอัตโนมัติ
6. **บันทึก.** เว็บไซต์จะอัปเดตอัตโนมัติภายในไม่กี่นาที! ✨

### กฎสำคัญ
- ❌ อย่าเปลี่ยนชื่อหรือสลับคอลัมน์ในแถวที่ 1 (แถวหัวข้อ)
- ❌ อย่าเพิ่มชีทพิเศษ — ระบบอ่านแค่ "Sheet 1" เท่านั้น
- ✅ คุณสามารถเรียงลำดับแถวได้ — เมนูจะแสดงตามลำดับที่เรียงไว้
